## План сајта УЖКК Студент Ниш

Преправићу сајт у вишестранични — задржавам „Modern editorial grid" дизајн (жута/плава, велика типографија), али додајем нове руте и секције према твојој жељи.

### Структура страница (руте)

```
/                 Почетна
/vesti            Листа свих вести
/vesti/$slug      Детаљ вести (слика + текст)
/klub             О клубу — историјат
/tim              Први тим + Стручни штаб
/mladje           Млађе категорије (тренери + селекције)
/galerija         Албуми фотографија + YouTube видео
/kontakt          Адреса, телефон, e-mail, лого кит
```

### Почетна страна
- Хero: насловна фотографија + назив клуба + грб (placeholder грб генеришем)
- Последње 3 вести (картице → води на `/vesti/$slug`)
- Логотипи такмичења: **КСС** (линк ka kss.rs) и **FIBA EuroCup Women** (линк ka fiba.basketball)
- Кратак историјат (1–2 пасуса, „Више →" води на `/klub`)
- Позив за упис у школу кошарке (CTA блок)
- Друштвене мреже: Инстаграм и YouTube (иконе)
- Партнери/спонзори на дну (placeholder логотипи)

### Картице/странице

**Вести** — мок подаци у `src/data/news.ts` (наслов, датум, слика, текст, slug). Лако се мењају дневно — једна датотека, један објекат по вести.

**О клубу** — историјат у дужој форми, кључни датуми, постигнућа.

**Тим** — мрежа картица играчица: фото, име и презиме, висина, године, место рођења, позиција. Испод тога секција „Стручни штаб" истим стилом.

**Млађе категорије** — картице тренера (фото + биографија) + групне фотографије селекција (плејсхолдери).

**Галерија** — једноставни албуми (наслов + грид сличица) + ред YouTube ембедова.

**Контакт** — адреса, телефон, e-mail, дугме „Преузми лого кит" (placeholder ZIP линк).

### Навигација
Sticky nav у `__root.tsx` са `<Link>` на све странице. Footer са друштвеним мрежама и спонзорима — заједнички за све странице.

### Технички детаљи
- TanStack file-based routing (`src/routes/*.tsx`), по једна `head()` са насловом/описом
- Заједнички `Header`/`Footer` компоненти у `src/components/site/`
- Мок-подаци у `src/data/` (вести, играчице, штаб, тренери) — лако ажурирање без backend-а
- Сви тренутни жути/плави токени и анимације се задржавају
- Генеришем додатне слике: грб клуба, насловна, портрети тренера, групне фотке селекција

### Шта НЕ радим у овом кораку
- Без админ панела / backend-а (Lovable Cloud) — све је мок. Ако касније желиш да вести/тим уноси неко без кода, можемо додати Cloud (база + проста админ страна).
- Лого кит је placeholder фајл — даш ми ZIP кад будеш имао.
